## [2.0.0] - 2026-11-03

The first release as Tack, a fork of [ClipHistory](https://github.com/weiykong/ClipHistory) rebuilt with native macOS controls and full-fidelity clips. If you're coming from a ClipHistory build of this fork, your history moves over on first launch.

### Added

- Every format on the clipboard is kept byte for byte, so images keep full resolution, and rich text and multiple files stay intact.
- The popup opens at the text cursor, falling back to the focused input field, then the mouse pointer.
- Links, email addresses and code are detected and shown differently. Searching "link", "email" or "code" finds them, and links can be opened from the right-click menu.
- List and grid layouts, switched with a button or `⌘L`.
- Paste as plain text with `⇧↵`, paste by position with `⌘1` to `⌘9`, and pin or delete with `⌘P` and `⌘⌫`.
- Settings to ignore clips from other devices, and to record passwords and other sensitive clips (off by default).
- Automated tests, CI and tagged releases.

### Changed

- Rebuilt for Swift 6 and macOS 26, with a Liquid Glass popup, native settings and a menu bar item.
- New name, identifier (`io.github.manan-santoki.tack`) and icon.
- History is stored as one encrypted file per clip, so large images don't slow down saving.
- Pinned clips are never removed by the history limit.
- Copying something already in your history moves it to the top instead of duplicating it.

### Removed

- The global keyboard event tap. The popup now takes focus directly.
- Support for macOS versions before 26.

### Fixed

- The shortcut recorder now captures new shortcuts.
- Saved settings, including excluded apps, are no longer reset on launch.
- A denied Keychain request no longer replaces the encryption key, which would have lost your history.
- Clips marked as transient or auto-generated by their app are no longer recorded by default.
